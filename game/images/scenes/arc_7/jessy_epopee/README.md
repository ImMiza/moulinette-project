## Prompts de génération

Base commune : « Illustration complète pour visual novel 16:9. Jessy et Ilona adultes, identités et vêtements fidèles aux sprites de randonnée du projet. Jessy : cheveux bruns, barbe sombre, lunettes rectangulaires, chemise sauge, short kaki, grand sac olive avec corde orange. Ilona : queue-de-cheval brune, lunettes noires, haut olive, short kaki, sac sombre. Personnages peints directement dans le paysage, trait fin et décors d'animation peints à la main. Randonnée contemporaine dans une vallée de montagne ensoleillée. Continuité de palette et de géographie entre les plans. Visages et action dans les deux tiers supérieurs pour la boîte de dialogue. Aucun texte, interface, bordure ni personnage ajouté. »

Variations par plan : marche et vaste vallée (01) ; surprise causée par un petit oiseau (02) ; animal roux dans les fougères (03) ; trois pierres dans un cours d'eau étroit et main tendue (04) ; main saisie et chaussure éclaboussée (05) ; prairie fleurie et minuscule fruit jaune à cinq pointes (06) ; carte tenue à l'envers puis tournée par Ilona, avec deux mains cohérentes pour Jessy (07) ; gourde passée sans essuyer le goulot (08) ; repos sur un rocher plat, sacs posés, village et lac minuscules (09) ; fruit intact examiné (10) ; fruit goûté et noyau étoilé (11) ; sandwichs, sans fruit visible pour les deux parcours (13) ; amitié paisible et biscuit (14) ; aveu embarrassé, Ilona surprise, sans réponse romantique anticipée (15).
