Pistes copiées depuis `game/audio/`. Une piste n'est visible qu'à partir du premier chapitre où elle est jouée ; les pistes jamais jouées sont rangées sous « Coulisses ». La mention entre parenthèses signale une piste déclarée mais jamais jouée, ou jamais référencée par les scripts.

Quelques musiques appelées par les fins n'existent pas dans les fichiers du jeu : une piste de secours est jouée à leur place (voir le rapport de maintenance).
