## Profils d'effets des choix

<Spoiler requires="arc2" note="profils observés du prologue à l'arc II">

La plupart des options appliquent l'un de ces profils, multiplié par 1, 2 ou 3 selon le poids du moment (×3 pour les menus pivots, par exemple à l'arc II, `arc_2_plage.rpy:490`). Les baisses de `jalousie` et `pression_stream` (et parfois d'`influence_theo`) ont un plancher à 0 (`max(0, …)`).

| Profil | Effets de base (×1) |
| --- | --- |
| Complicité | `lien_jessy_ilona +2` |
| Espace laissé à Ilona | `autonomie_ilona +2`, `communication +1`, `confiance +1`, `pression_stream -1` ; souvent `ilona_peut_finir_ses_phrases +1` |
| Parole sincère | `communication +2`, `confiance +1`, `jalousie -1`, `lien_jessy_ilona +1` |
| Évitement | `communication -2`, `confiance -1`, `pression_stream +1`, `evitements +1` |
| Contrôle | `autonomie_ilona -2`, `confiance -2`, `influence_theo +1`, `jalousie +3`, `lien_jessy_ilona -1`, `controles +1` |

Le commentaire `script.rpy:237-238` appelle « tier C » l'évitement et « tier D » le contrôle. Le profil « contrôle » apparaît à l'arc II (premier menu, `arc_2_plage.rpy:78`). Quelques options sortent de ces profils (par exemple « Proposer de refaire la photo » : `communication +1`, `jalousie +1`).

</Spoiler>

## État de la relation

<Spoiler requires="arc5" note="lecture figée à l'arc V">

`etat_relation()` (`script.rpy:283-323`) renvoie `"proche"`, `"fragile"` ou `"distant"` :

- `ecoute = ilona_peut_finir_ses_phrases + interruptions_reparees`
- `controle = max(0, interruptions_ilona - interruptions_reparees)`
- `espace = autonomie_ilona × 4 + ilona_peut_finir_ses_phrases × 6 + interruptions_reparees × 6 + communication + confiance`
- `dette = influence_theo × 3 + controle × 8 + pression_stream × 2 + jalousie × 2 + confidences_laplage × 4`
- `indice = espace - dette`

| Résultat | Condition (dans l'ordre) |
| --- | --- |
| `distant` | `controle >= 3` |
| `proche` | `indice >= 200` (`SEUIL_ETAT_PROCHE`) et `ecoute >= 4` (`SEUIL_ETAT_ECOUTE`) |
| `fragile` | `indice >= 40` (`SEUIL_ETAT_FRAGILE`) |
| `distant` | sinon |

Seuils : `script.rpy:414-416`. À l'arc V, le résultat est figé dans `arc5_etat_relation` (`arc_5_examens.rpy:1510`) : il choisit la confidence à Laplage, la formulation de la question à la gare et une option de réponse.

</Spoiler>

<Spoiler requires="arc6">

À l'arc VI, `arc6_palier()` (`arc_6_diplomes.rpy:35-42`, appelée l. 159) traduit l'état en ton : `proche` → `"jessy"`, `fragile` → `"indecis"`, `distant` → `"theo"` (`arc6_penchant`). Ce ton change des répliques, pas la route.

</Spoiler>
