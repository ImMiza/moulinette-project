:::note[Repères]
Chaque arc a son tableau, protégé par sa clé. Les options sont recopiées telles qu'elles s'affichent en jeu ; la colonne « Ligne » indique où commence le `menu:` dans le script. Les jauges sont expliquées dans [Variables](../variables/), le calcul de la route dans [Calcul de l'embranchement](../verdict-arc-6/). « Plancher 0 » signifie que la valeur ne descend pas sous zéro.
:::
