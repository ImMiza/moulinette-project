## Comment fonctionnent les spoilers

Tout ce qui dépasse votre progression est masqué : texte, images, noms et pistes audio. Rien n'est chargé ni lu par un lecteur d'écran avant que vous cliquiez sur « Afficher ». Indiquez votre progression une fois sur la page [Ma progression](guide/progression/) : elle est enregistrée dans votre navigateur seulement, et les sections correspondantes s'ouvrent seules. Les deux routes et leurs fins se débloquent indépendamment.
